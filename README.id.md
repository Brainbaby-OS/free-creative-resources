## PPT sidang skripsi untuk diisi sendiri

[Unduh template .pptx](resources/id/template-sidang-skripsi.pptx) · [Petunjuk pengisian](resources/id/template-sidang-skripsi.md) · [Panduan presentasi AI Bahasa Indonesia](https://brainbaby.ai/id/blog/cara-membuat-presentasi-dengan-ai)

File berisi delapan slide dengan teks dan catatan pembicara yang dapat diedit: judul, latar belakang, pertanyaan penelitian, metode, hasil, pembahasan, kesimpulan dan referensi. Tidak ada hasil penelitian atau kutipan contoh yang dibuat-buat. Tidak ada animasi atau grafik contoh.

Buka file dan ganti semua teks dalam kurung siku dengan bahan yang sudah Anda periksa. Sesuaikan struktur dengan ketentuan kampus. Tambahkan tabel atau grafik dari data asli bila diperlukan. Periksa font, urutan dan potongan teks setelah membuka atau mengimpor file ke aplikasi tujuan.

Di GitHub, buka file lalu pilih **Download raw file**. Mengunduh dan mengisi sendiri tidak memerlukan akun Brainbaby. Jika memakai AI untuk menyusun draf, periksa batas akun serta aturan penggunaan AI dari kampus. Unduhan tidak menambah kredit atau menjalankan AI secara otomatis.
