Brainbaby · Edition 2026-10-06 · Blank planning resource · CC BY 4.0

Use the same task and instructions to compare image tools before buying more attempts. This kit contains proposed exercises and empty records, not benchmark results or a ranking. Copy it into a text editor, fill the fields, and keep it with your source and output files.

## Exercise A — Generate one product concept

Use the same complete prompt in each tool:

> A blue ceramic cup on a pale studio background, soft light from the left, a subtle contact shadow, centered composition with space above for a headline. Keep the handle visible. No lettering, logo or extra objects.

Check: one cup; blue glaze; visible handle; pale background; left-side light; space above; no added text. Treat these as proposed requirements, not a promise of any tool's result. Save the exact prompt, settings and original output.

## Exercise B — Compose a scene with several constraints

> A wide editorial illustration of a small community garden: three raised beds in the foreground, a path between them, two fictional adult volunteers near the tool shed in the background. Warm late-afternoon light, clear separation between the beds, no signs or lettering.

Check: three beds; a visible path; two adult volunteers; shed in the background; wide composition; no unintended lettering. Record missing or duplicated objects instead of assigning an unsupported general quality score.

## Exercise C — Edit an authorized source photo

Use the same source file for each tool that supports editing:

> Replace only the cluttered background with a plain light-gray studio background. Keep the cup's shape, blue glaze, handle position and original crop unchanged. Match the original lighting and contact shadow. Do not add lettering, decorations or extra objects.

Adapt “cup” to your actual subject before starting; use that exact adapted wording in every tool. Compare the result with the source at full size. If a tool does not accept source photos, mark this exercise **unsupported**, rather than silently comparing a new generated concept to an edit.

Share the blank kit or a redacted record. Keep source photos, private prompts, account IDs and payment receipts out of a public review. Include the date, task, settings, observed limitations and any edits you made to the kit. Leave unknowns as unknowns.
