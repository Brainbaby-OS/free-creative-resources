# Educational Course Outline

Start a course with what learners should be able to do. Use this seven-slide outline to align modules, practice and assessment.

## 1. Learners and prerequisites

Describe the audience, prior knowledge and access requirements.

## 2. Learning objectives

Use observable actions such as compare, build or diagnose.

## 3. Course map

List modules in the order skills depend on one another.

## 4. Lesson structure

Plan a short explanation, worked example and practice task for each module.

## 5. Exercises

Include instructions, estimated time and a rubric.

## 6. Assessment

Explain how learners demonstrate each objective and how feedback is delivered.

## 7. Resources and next steps

Provide source material, accessibility alternatives and further practice.
