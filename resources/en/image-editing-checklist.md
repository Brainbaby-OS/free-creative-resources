Keep an untouched copy of the source. Avoid uploading private information that the edit does not require. Crop out unrelated material where appropriate.

## 2. Write a bounded edit instruction

Change: [one background, lighting, object or framing detail].
Preserve: [subject shape, placement, colors and relevant text].
Use the attached image as the source. Do not introduce new brand marks, product features or unsupported claims. Flag details that cannot be preserved accurately.

Illustrative example for your own product photo:
“Replace the cluttered background with a plain light-gray background. Keep the cup's shape, blue glaze and handle position unchanged. Do not add lettering or decorations.”

This is an example brief, not a generated output or a performance promise.

## 3. Check before submitting

- [ ] The attached thumbnail is the intended source.
- [ ] The file meets the uploader's current size and format rules.
- [ ] The requested change is specific.
- [ ] Required details are listed explicitly.
- [ ] The current credit cost and allowance are understood.
- [ ] No unnecessary sensitive data is included.

## 4. Review the result at full size

- [ ] Shape and proportions match the source where required.
- [ ] Edges, handles, reflections and shadows are plausible.
- [ ] Colors and material details remain accurate.
- [ ] Every visible word and number has been compared with the source.
- [ ] No product property, logo or endorsement was invented.
- [ ] The file opens and fits the destination's requirements.

Do not use an attractive thumbnail as proof of accuracy. Use conventional editing when exact typography or pixel-level preservation is required.
