# Presentation compatibility and handoff checklist

Brainbaby · Edition 2026-10-19 · Blank review resource · CC BY 4.0

Use this worksheet to review a presentation in the application and device that will receive it. It contains proposed checks and empty records, not measured software scores. A PowerPoint filename does not prove that every object remains editable or that every visual effect will transfer.

Keep an untouched original. Work with a copy you have permission to use. Do not enable macros, scripts or untrusted embedded content to run a compatibility check. A review should not require changing security settings.

## Check 1 — Text and fonts

Open the working file. Change one heading and one body paragraph, save a new copy, close it and reopen it. Check line breaks, symbols, accents, text clipping and font substitutions. If a required font is unavailable, record the agreed substitute and review the layout again.

## Check 3 — Notes, links and media

Inspect required speaker notes, links, audio and video. Test only expected, trusted links and media. Confirm what remains in the delivery copy, and whether it depends on a network connection. Mark missing sample features not tested rather than guessing that they work.

## Check 4 — Visual reference

Compare the working file with an approved PDF reference, slide by slide. Review spacing, image crops, contrast, slide dimensions and essential labels. A visual mismatch may require a correction even if the content is editable. Confirm the facts and source notes separately; a compatibility pass is not a fact check.

## Check 5 — Final presentation device

Open the exact delivery copy in the intended application and rehearse the slide sequence. Test any required offline access before relying on it. Check the screen or projector setup, presenter view and required media. Do not assume a successful export means the meeting device is ready.
